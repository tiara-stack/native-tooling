# Issue tracker

Work items for this repository live in Linear.

- Team: `tiara-stack`
- Default destination: the team backlog
- No project, cycle, priority, assignee, or other issue workflow rules

Use Linear MCP to create, read, list, comment on, and update issues. Create specs and other work items as new issues in the `tiara-stack` backlog. Use the labels mapped in `docs/agents/triage-labels.md`.
